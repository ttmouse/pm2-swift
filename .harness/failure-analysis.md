# Failure Analysis

Agent 犯错后必须记录，防止同类错误再次出现。

## 记录模板

```md
## 失败记录

### 任务
[任务描述]

### 错误
[错在哪里]

### 发现方式
[如何发现的：编译报错 / 测试失败 / 人工指出]

### 根因
[为什么会出现]

### 失败类型
- [ ] 对项目了解不足（缺少上下文）
- [ ] 规则未遵守（规则不够清晰或没读到）
- [ ] 技术误判（对代码或框架理解错误）
- [ ] 粗心（忘了某步验证）

### 预防措施
[下次如何避免]

### 需新增
- [ ] 规则（.qoder/rules/）
- [ ] 测试
- [ ] 验证脚本
- [ ] Harness 文档（.harness/）
- [ ] 上下文说明（CONTEXT.md）
```

## 核心原则

**同类错误出现第二次，不要只修代码，要修 harness。**

即：
- 缺少规则 → 加规则
- 缺少测试 → 加测试
- 缺少验证 → 加验证脚本
- 缺少上下文 → 更新 CONTEXT.md
- 边界不清 → 更新 working-boundaries.md
